# Portfólio Arthur: https://portfolio-seven-umber-ldnh0lh5ob.vercel.app/

Portfolio  desenvolvido para apresentar meus projetos de GIS, planejamento urbano e desenvolvimento.

## Stack

Construído com React, TypeScript, Vite, Tailwind CSS e shadcn/ui. Formulário de contato integrado com Formspree. Imagens otimizadas em AVIF com fallback PNG.

## Deploy

Hospedado na Vercel com deploy automático via GitHub. SEO configurado com sitemap.xml e robots.txt.

## Estrutura

- `/src/pages` - Páginas principais (Home, ProjectDetail)
- `/src/components` - Componentes reutilizáveis
- `/src/data` - Dados dos projetos e informações
- `/public` - Assets estáticos (imagens, vídeos)

## Performance

- Lazy loading de imagens
- AVIF format com fallback
- Code splitting automático
- Core Web Vitals
